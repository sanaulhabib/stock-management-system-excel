# 📦 Stock Management System | Excel

An Excel-based **Stock Management System** designed to manage inventory records, track stock movements, and monitor available stock efficiently.

## 📌 Project Overview

This project simplifies inventory management by organizing stock information in Excel. It helps track stock in and stock out, monitor available quantities, and maintain accurate inventory records using Excel formulas.

## 🎯 Project Objective

The main objective of this project was to demonstrate how **Excel can be used to manage inventory efficiently**, automate stock calculations, reduce manual errors, and maintain organized stock records.

## 🔧 Key Features

- Stock In and Stock Out Tracking
- Automatic Stock Balance Calculation
- Inventory Record Management
- Stock Quantity Monitoring
- Automated Calculations Using Excel Formulas

## 🧮 Excel Functions Used

- VLOOKUP
- IF
- SUMIF
- IFERROR

## 💡 Key Learning

Through this project, I gained hands on experience in:

- Building a practical inventory management system in Excel
- Managing stock records in an organized way
- Applying Excel formulas to automate calculations
- Tracking stock movements and available quantities
- Developing an Excel-based solution for inventory management
